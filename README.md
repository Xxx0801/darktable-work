# darktable-work

darktable 摄影后期修图助手。

## 用途

这是一个基于 [darktable](https://www.darktable.org/) 免费开源软件的摄影后期辅助 Skill。它帮助用户：

1. **分析照片** — 判断摄影类型、光线情况、当前问题。
2. **给出修图方案** — 按 darktable 实际功能提供专业、可执行的调整步骤。
3. **解释调整逻辑** — 说明每一步为什么这样调，而不是机械套参数。
4. **提供进阶建议** — 局部遮罩（Mask）、局部曝光/色彩、风格化方向。

面向摄影初学者和进阶用户，强调「理解照片问题 + 调整逻辑 + 后期思维」。

## 使用方式

在对话中直接描述你的照片或修图需求即可，例如：

- 「帮我看看这张人像怎么修」+ 上传照片
- 「这张风光照片天空过曝了怎么处理？」
- 「我想修成日系清透风格，该怎么做？」
- 「这张夜景照片噪点很多怎么办？」

Skill 会按照以下结构回答：

1. **照片分析** — 摄影类型 / 光线情况 / 当前问题
2. **darktable 修图步骤** — 模块（中文+英文）/ 调整方向 / 建议范围 / 原因
3. **进阶优化** — Mask 局部调整 / 局部曝光 / 局部色彩 / 风格化
4. **注意事项** — 直方图、参数、格式提醒

> 建议上传照片或说明：拍摄环境、相机型号、JPG 或 RAW、想要的风格，以获得更精准的方案。

## 支持场景

- 人像摄影后期（自然人像 / 日系 / 电影感 / 环境人像）
- 风光摄影后期（自然风光 / 新疆·西北 / 城市建筑 / 日落 / 夜景）
- 旅行摄影后期
- 城市摄影后期
- 夜景摄影后期

## 专业规范

- 模块名一律使用「中文名称（英文名称）」格式，不单独使用英文。
- 优先推荐 darktable 4.x 之后的模块。
- 强调观察直方图、保留真实信息、摄影表达。
- 不鼓励过度锐化、不鼓励破坏肤色。

## 未来扩展方向
