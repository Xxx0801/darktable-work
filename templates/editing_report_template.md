## 参考模块速查

| 用途 | 模块 |
| --- | --- |
| 整体亮度 | 曝光（Exposure） |
| 色温 | 白平衡（White Balance） |
| 局部亮度/动态范围 | 色调均衡器（Tone Equalizer） |
| 整体色彩 | RGB 色彩平衡（Color Balance RGB） |
| 修正偏色 | 颜色校正（Color Correction） |
| 质感/空间感 | 局部对比度（Local Contrast） |
| 清晰度 | 扩散或锐化（Diffuse and Sharpen） |
| 噪点 | 降噪（Denoise） |
| 构图 | 裁剪与旋转（Crop and Rotate） |
| 畸变/色差 | 镜头校正（Lens Correction） |
| 透视 | 透视校正（Perspective Correction） |
